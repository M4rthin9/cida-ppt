# จากคลิปงานฝึกวิชาชีพจริง → 150 เฟรม → ภาพเคลื่อนไหวตามการเลื่อน

คู่มือนี้สำหรับฝ่ายฝึกวิชาชีพผู้ต้องขัง ทัณฑสถานบำบัดพิเศษกลาง เริ่มจากการถ่ายคลิปด้วยโทรศัพท์จนได้ไฟล์ `public/frames/_150.zip` สำหรับ hero ที่มีอยู่แล้ว ตัว animation ที่เตรียมไว้ทำหน้าที่เป็นภาพพื้นหลัง โดยตั้งใจรักษาข้อความ เมนู ปุ่ม สี และการจัดวางเดิม

**สถานะงานนี้:** เตรียมคู่มือ ตัวสร้าง ZIP และ player ที่นำไปใช้ต่อได้ไว้แล้ว ตามที่เลือกไว้ยังไม่เชื่อม player เข้าหน้าแรก ในโครงการยังไม่มีคลิปจริงและ `_150.zip` จึงยังสร้างเฟรมผลงานจริงให้ไม่ได้ การนำเข้าสร้างชุดภาพและ manifest ให้พร้อมใช้งาน ส่วนการแสดงบนหน้าแรกต้องเชื่อม `ScrollSequence` หลัง hero เดิมในขั้นตอนถัดไป

หากต้องการทำตามแนวภาพต้น–ภาพปลายแล้วสร้างคลิปต่อเนื่องแบบ [คลิปอ้างอิงของคุณตั้งแต่นาที 6:09](https://www.youtube.com/watch?v=y1pM7bS6IY8&t=369s) ดูเส้นทาง AI และ prompt ที่ [CINEMATIC-PROMPTS.md](CINEMATIC-PROMPTS.md) แล้วนำคลิปที่ได้กลับมาเริ่มที่ขั้นตอน 3 ของคู่มือนี้

## 1. เลือกภาพที่จะถ่าย

เริ่มด้วยผลงานจริงเพียงชิ้นเดียว เช่น ดอกไม้ประดิษฐ์ งานไม้ หรืองานเย็บปักถักร้อย เลือกช็อตเดียวต่อเนื่อง 6–10 วินาที ตัวอย่างที่ทำง่ายคือวางผลงานนิ่ง แล้วเคลื่อนกล้องช้า ๆ จากมุมเฉียงเข้าหาชิ้นงาน หรือวางกล้องนิ่งแล้วถ่ายการทำงานของมือหนึ่งจังหวะ

สำหรับชุดแรกแนะนำ **ช็อตผลงานบนโต๊ะ ความยาว 8 วินาที** เพราะจัดแสงและตรวจความต่อเนื่องได้ง่าย ภาพเคลื่อนไหวจะย้อนกลับเมื่อผู้ชมเลื่อนขึ้น จึงควรเลือกการเคลื่อนไหวที่ดูเป็นธรรมชาติทั้งสองทิศทาง

## 2. จัดฉากและถ่ายด้วยโทรศัพท์

1. ถ่ายแนวนอน 16:9 ที่ 1080p / 30 fps ใช้ขาตั้งหรือพยุงโทรศัพท์ให้มั่นคง
2. ใช้ฉากหลังเข้มเรียบ ให้ผ้าหรือฉากกินพื้นที่ถึงขอบภาพ ไม่ให้เห็นขอบโต๊ะหรือรอยต่อที่รบกวนสายตา
3. ใช้แสงนุ่มโทนอุ่นจากด้านข้าง ให้เห็นผิววัสดุและรายละเอียดของงาน โทนเข้มและทองควรมาจากแสงกับฉากจริง โดยยังรักษาสีจริงของผลงาน
4. เผื่อพื้นที่ว่างรอบชิ้นงานสำหรับข้อความ hero เดิม และวางรายละเอียดสำคัญใกล้กึ่งกลาง เพราะจอมือถือจะตัดด้านข้างของภาพออก
5. ล็อกโฟกัสและความสว่างถ้าโทรศัพท์รองรับ แล้วเคลื่อนกล้องหรือชิ้นงานช้า ๆ ด้วยความเร็วคงที่ หลีกเลี่ยงการซูมกระชาก
6. บันทึกประมาณ 10–12 วินาที เผื่อเลือกช่วงนิ่งและต่อเนื่อง 8 วินาทีภายหลัง ไม่ใส่ข้อความ โลโก้ เส้นขอบ ทรานซิชัน หรือการตัดสลับหลายช็อตลงในคลิป

ดูคลิปเต็มหนึ่งรอบก่อนนำเข้า: ต้องไม่มีช่วงโฟกัสหลุด แสงเปลี่ยนฉับพลัน ภาพสั่น หรือมือบังเลนส์ เสียงจะไม่ถูกใช้ใน sequence นี้

## 3. ย้ายคลิปต้นฉบับเข้าเครื่อง

คัดลอกคลิปจากโทรศัพท์โดยตรง เช่น `E:\video\hero.mp4` เพื่อรักษาคุณภาพต้นฉบับ ไม่จำเป็นต้องวางคลิปไว้ใน `public` และไม่ต้องอัปโหลดผ่าน CMS

เลือกช่วงที่ต้องการ เช่น คลิปยาว 12 วินาที ใช้ช่วงวินาทีที่ 2 ถึง 10 จะได้ `--start 2 --duration 8` ทั้ง 150 ภาพจะเรียงมาจากช่วงนี้

## 4. ตรวจเครื่องมือครั้งแรก

เปิด Terminal ที่โฟลเดอร์โครงการ `E:\cida-ppt` โครงการต้องติดตั้ง dependencies ไว้แล้วตาม [SETUP.md](../SETUP.md)

```powershell
cd E:\cida-ppt
python --version
ffmpeg -version
ffprobe -version
```

ตัวช่วยใช้ Python 3.9 ขึ้นไปและ FFmpeg พร้อม FFprobe ไม่ต้องติดตั้งไลบรารี Python เพิ่ม `pnpm` จะเลือก `python` / `py -3` / `python3` ให้ตามระบบ หาก PowerShell ไม่ยอมรัน `pnpm` ให้ใช้ `pnpm.cmd` แทน

ถ้า `ffmpeg` ไม่อยู่ใน PATH ให้ใช้ `--ffmpeg` พร้อมตำแหน่งไฟล์จริงได้เลย ตัวช่วยจะหา `ffprobe` ในโฟลเดอร์เดียวกัน เครื่องนี้พบ FFmpeg ที่ `H:\New folder\ffmpeg\bin\ffmpeg.exe` จึงใช้คำสั่งแบบระบุเส้นทางในขั้นถัดไปได้ หากติดตั้งเครื่องใหม่ ดู [หน้า Download ของ FFmpeg](https://ffmpeg.org/download.html)

## 5. สร้าง ZIP ที่มี 150 เฟรม

เมื่อ FFmpeg อยู่ใน PATH ให้รัน:

```powershell
pnpm frames:make "E:\video\hero.mp4" --start 2 --duration 8
```

สำหรับตำแหน่ง FFmpeg ที่พบในเครื่องนี้:

```powershell
pnpm frames:make "E:\video\hero.mp4" --start 2 --duration 8 --ffmpeg "H:\New folder\ffmpeg\bin\ffmpeg.exe"
```

เปลี่ยนตำแหน่งคลิปให้ตรงกับไฟล์ของคุณ หากคลิปที่ตัดไว้ยาว 8 วินาทีพอดี ให้ใช้ `--start 0 --duration 8`

ผลลัพธ์คือ **`E:\cida-ppt\public\frames\_150.zip`** ภายในมี `frame-001.png` ถึง `frame-150.png` ครบ 150 ไฟล์ ใช้ชื่อนี้ได้ทันทีโดยไม่ต้องเปลี่ยนเป็น `frame150.zip`

ตัวช่วยเลือกภาพกระจายตลอดช่วงคลิป ลดความกว้างลงเหลือไม่เกิน 1280 พิกเซลโดยรักษาอัตราส่วน และไม่ขยายภาพที่เล็กอยู่แล้ว คลิปต้นฉบับไม่ถูกแก้ไข ค่าเริ่มต้นนี้ช่วยลดภาระดาวน์โหลดและหน่วยความจำบนมือถือ หากต้องการตรวจคุณภาพที่ใหญ่ขึ้น ให้เพิ่ม `--width 1600` แล้วทดสอบบนมือถือจริงด้วย

ถ้าต้องการชื่อ `frame150.zip` โดยเฉพาะ:

```powershell
pnpm frames:make "E:\video\hero.mp4" --start 2 --duration 8 --output "E:\video\frame150.zip"
pnpm frames:import "E:\video\frame150.zip"
```

ถ้ามี ZIP ชื่อเดิมอยู่แล้ว ตัวช่วยจะหยุดเพื่อรักษาไฟล์เดิม เพิ่ม `--overwrite` เมื่อคุณต้องการแทนที่ ZIP นั้น หากต้องการเก็บหลายรุ่น ให้ใช้ `--output` ตั้งชื่อใหม่

## 6. นำเข้าเฟรม

สำหรับไฟล์ตำแหน่งมาตรฐาน ให้รัน:

```powershell
pnpm frames:import
```

หรือถ้ามี ZIP จากช่างภาพอยู่แล้ว ให้นำเข้าจากตำแหน่งจริงได้โดยไม่ต้องแปลงวิดีโอใหม่:

```powershell
pnpm frames:import "E:\video\frame150.zip"
```

ตัวนำเข้าตรวจชื่อภาพครบ 001–150 ตรวจโครงสร้าง PNG และขนาดภาพที่ต้องเท่ากันทั้งหมด จากนั้นคัดลอก PNG โดยไม่แก้ไขข้อมูลภาพ และสร้าง `public/frames/manifest.json` เป็นขั้นตอนสุดท้าย หาก ZIP ไม่ผ่านการตรวจ ชุดเฟรมเดิมจะยังอยู่

## 7. เปิดเว็บและตรวจหลังเชื่อม animation

ขั้นตอนนี้ใช้เมื่อเชื่อม `ScrollSequence` หลัง hero เดิมแล้ว ตัว player เตรียมช่วงเลื่อน `450svh` และ canvas ตรึงเต็มหน้าจอไว้ หากยังไม่ได้เชื่อม การนำเข้าเพียงอย่างเดียวยังไม่เปลี่ยนหน้าแรก

สำหรับผู้พัฒนาที่จะเชื่อมต่อภายหลัง: ใช้ `sequenceVersion()` จาก `src/lib/vocational/sequence-assets.ts` ตรวจว่ามี manifest และเฟรมครบก่อนส่ง HTML แล้วส่งค่า `version` ให้ `ScrollSequence` จาก `src/components/vocational/ScrollSequence.tsx` พร้อมเนื้อหา hero เดิมผ่าน `children` เก็บภาพนิ่งเดิมเป็น fallback และใช้ stage จาก player เพียงชั้นเดียว อย่านำ hero ที่มีพื้นหลังทึบและ sticky wrapper ซ้ำอีกชั้นมาบัง canvas ต้องตรวจตำแหน่งเนื้อหาและพื้นหลังของ hero ปัจจุบันก่อนเชื่อมจริง

หากเซิร์ฟเวอร์กำลังรันอยู่ ให้หยุดด้วย `Ctrl+C` ก่อน แล้วเริ่มใหม่:

```powershell
pnpm dev
```

เปิดหน้าแรกที่ [localhost:3000](http://localhost:3000) แล้วทดสอบตามนี้:

1. ตอนเริ่ม hero ต้องเป็นเฟรม 001 เมื่อเลื่อนถึงปลายช่วงที่ตรึง hero ต้องเป็นเฟรม 150
2. เลื่อนช้า เลื่อนเร็ว และเลื่อนย้อนกลับ ภาพต้องตามตำแหน่งเลื่อนและค่อย ๆ เข้าหาเฟรมเป้าหมาย เมื่อหยุดเลื่อนภาพจะหยุดหลังการเกลี่ยสั้น ๆ
3. ลองย่อหน้าต่างและเปิดด้วยมือถือ ภาพต้องเต็มพื้นที่โดยไม่มีขอบว่าง เมนู ข้อความ และปุ่มเดิมยังอ่านและกดได้
4. เปิด Reduce Motion / ลดการเคลื่อนไหวในระบบ ภาพต้องอยู่นิ่งและไม่ต้องเลื่อนผ่านพื้นที่ animation ยาว
5. ตรวจว่าข้อความเดิมไม่ทับรายละเอียดสำคัญ ถ้าภาพจัดวางไม่เหมาะ ให้ปรับการถ่ายหรือครอปคลิปต้นทาง แทนการเปลี่ยน UI

สำหรับ production ให้นำเข้าก่อน `pnpm build` แล้วรวม `public/frames` ในการส่งขึ้นเซิร์ฟเวอร์ด้วย การสร้าง ZIP และนำเข้าในเครื่องยังไม่ใช่การ deploy เว็บไซต์

## หากติดปัญหา

| อาการ | วิธีแก้ |
| --- | --- |
| `Archive missing` | รันขั้นตอนสร้าง ZIP หรือระบุเส้นทาง ZIP ที่มีอยู่จริง |
| `FFmpeg not found` | เพิ่ม FFmpeg ลง PATH หรือใช้ `--ffmpeg` พร้อมเส้นทางเต็ม |
| `Selected range exceeds the video duration` | ลด `--start` หรือ `--duration` ให้ช่วงที่เลือกไม่เลยท้ายคลิป |
| `Missing frames` / `Mismatched dimensions` | ใช้ตัวช่วยสร้าง ZIP ใหม่จากคลิปเดียว หรือตรวจชุดไฟล์ของช่างภาพให้ครบและขนาดเท่ากัน |
| ยังเห็นภาพพื้นหลังนิ่ง | ตรวจว่านำเข้าสำเร็จ มี `manifest.json` และเชื่อม player เข้ากับ hero แล้ว รีสตาร์ต `pnpm dev` และตรวจ Reduce Motion ด้วย |
| โหลดภาพช้าบนมือถือ | สร้างชุดใหม่โดยใช้ `--width 960` และตรวจรายละเอียดผลงานก่อนนำไปใช้ |

รายละเอียดการเลือกอัตราเฟรม การจำกัดจำนวนภาพ และการส่งออก image sequence อ้างอิง [เอกสาร FFmpeg](https://ffmpeg.org/ffmpeg-all.html) อัตราเฟรมของการแปลงคลิปใช้เพื่อเตรียมไฟล์เท่านั้น การเล่นบนหน้าเว็บขับเคลื่อนด้วยตำแหน่ง scroll
